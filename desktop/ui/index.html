需要 Python 3.10 或更高版本

Nyra 桌面端使用本机的 Python 运行 Nyra，但没有找到 Python 3.10+。

Nyra needs Python 3.10+ on this computer.

macOS

系统自带的 python3 是 3.9，版本不够。任选一种：

  • 从 python.org 下载安装包；
  • 或用 Homebrew：brew install python

Windows

  • 从 python.org 下载安装，安装时勾选 “Add python.exe to PATH”；
  • 或在终端运行：winget install Python.Python.3.12

    
装好后再安装 Nyra（见下一步），然后点 “重新检测”。

macOS

      
git clone https://github.com/js2005happy/nyra.git
cd nyra

Windows（PowerShell）

      
irm https://raw.githubusercontent.com/js2005happy/nyra/main/scripts/install.ps1 | iex

      
单文件 nyra.exe（Node 运行时）暂不支持桌面端，仍需上面装好的 Python 版 Nyra。

    

    
已经 clone 在别处？设置环境变量 NYRA_SOURCE 指向仓库目录；或用 NYRA_PYTHON 指定 Python。
