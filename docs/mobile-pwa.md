# 手机安装 Nyra 网页界面（PWA）

Nyra 的网页界面可以像 App 一样装到手机主屏幕上：安卓用 Chrome，iPhone
用 Safari。不用应用商店，也没有 APK / IPA——手机上打开的是电脑上跑着
的 Nyra 服务。

> 如实说明：这套 PWA 只在本机上搭起来并通过了测试，**还没有在真手机
> 上装过**。下面步骤按浏览器标准流程写，第一次在真机上装时如有出入，
> 以手机上实际出现的菜单为准。

## 先决条件

- 电脑和手机连**同一个 Wi-Fi**。
- 电脑上 Nyra 服务正在跑（见下）。

## 第 1 步：在电脑上启动服务（允许局域网访问）

默认 `python3 -m nyra ui` 只绑 `127.0.0.1`，本机能开、手机打不开。
要让手机访问，启动时改绑所有网卡：

```bash
python3 -m nyra ui --host 0.0.0.0
```

启动后终端会打印一行警告（非本机地址有风险，见下）与一个含 token
的链接，例如：

```text
http://127.0.0.1:8765/?token=xxxxxxxx
```

这个链接里的 `127.0.0.1` 是电脑自己的地址，手机上打不开。把它换成
电脑的局域网 IP：

- Windows：`ipconfig`，看“IPv4 地址”（一般是 `192.168.x.x`）。
- macOS / Linux：`ip addr` 或 `ifconfig`，看 `en0` / `wlan0` 的 `inet`。

换好后手机上打开：

```text
http://192.168.x.x:8765/?token=xxxxxxxx
```

token 每次启动都会变。服务重启后，手机上要重新打开终端里新打印
的链接。

## 第 2 步：安装到主屏幕

**安卓（Chrome）：**

1. 手机 Chrome 打开上面那个链接，确认 Nyra 页面能正常打开。
2. 点右上角 ⋮ 菜单 → **添加到主屏幕**（或“安装应用”，Chrome 版本
   不同叫法不同）。
3. 主屏幕出现 Nyra 图标，点开就是全屏的 Nyra 界面。

**iPhone（Safari）：**

1. 手机 Safari 打开上面那个链接，确认 Nyra 页面能正常打开。
2. 点底部的“分享”按钮 → **添加到主屏幕**。
3. 主屏幕出现 Nyra 图标，点开就是全屏的 Nyra 界面。

## 已知限制

- **点主屏幕图标会先看到“需要访问 token”的页面。** token 是每次启
  动随机生成的，没法写进安装包的静态 manifest 里（`start_url` 是 `/`）。
  正确流程是：先在浏览器里打开终端打印的带 token 链接，确认能用，
  再添加到主屏幕；服务重启后，重新打开新链接。
- **没有离线能力。** PWA 只是个全屏的浏览器壳，没有 Service Worker；
  电脑上的服务停了，手机上也就打不开。手机本身不跑 Nyra。
- **图标是 SVG。** manifest 与 iOS 触摸图标都用仓库里的
  `docs/assets/nyra-mark.svg`（光标标志）；部分旧机型可能不显示
  SVG 图标，改用 PNG 后再更新 manifest。

## 安全警告（重要）

- `--host 0.0.0.0` 会让**同一 Wi-Fi 里的任何设备**都能访问这个服务，
  而唯一的屏障就是链接里的 token。只在自己信任的家庭 Wi-Fi 下这么用。
- **绝不要把 8765 端口映射到公网**（路由器端口转发、内网穿透等）。
  token 一旦泄露，任何人都能通过这个界面读写文件、执行命令。
- token 不要发到群聊、截图里不要带上完整链接。用完可以 Ctrl+C
  停掉服务，下次启动会换一个新 token。
