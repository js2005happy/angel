安装 NyraInstall Nyra

五步，几分钟。只需要 Python 和 git。Five steps, a few minutes. All you need is Python and git.

0 / 5 步已完成steps done

macOS

  1. 1✓

    前置要求Prerequisites

    需要 Python 3.10 或更高版本，以及 git。先确认一下版本：You need Python 3.10 or later, and git. Check your versions first:

    python3 --version
    git --version
  2. 2✓

    克隆仓库Clone the repository

    把代码下载到本地的 nyra 文件夹，然后进入它。Download the code into a local nyra folder, then step into it.

    git clone https://github.com/js2005happy/nyra.git nyra && cd nyra
  3. 3✓

    设置一个模型 KeySet a model key

    14 个模型预设任选其一，这里以 DeepSeek 为例。Key 只从环境变量读取，不会写进文件。Pick any of the 14 model presets; DeepSeek is shown here. Keys are read from environment variables and never written to files.

    export DEEPSEEK_API_KEY=sk-...
  4. 4✓

    运行Run it

    在终端里开始交互会话，或者打开本地网页界面。Start an interactive session in the terminal, or open the local web UI.

    终端交互Terminal
    python3 -m nyra
    本地网页界面Local web UI
    python3 -m nyra ui
  5. 5✓

    验证Verify

    能打印出版本号，就说明装好了。If it prints a version number, you’re all set.

    python3 -m nyra --version
