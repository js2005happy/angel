安装 NyraInstall Nyra

最新版 v0.5.1。单文件二进制，不用装 Python、Node 或 Bun。Latest release v0.5.1. One self-contained binary; no Python, Node or Bun needed.

  1. 1

    下载命令行版Download the command-line app

    Apple 芯片的 Mac 用这条；Intel Mac 用下面那条。Use this on Apple silicon; on an Intel Mac use the line below it.

    $curl -fL -o nyra https://github.com/js2005happy/nyra/releases/latest/download/nyra-macos-arm64 && chmod +x nyra
    $curl -fL -o nyra https://github.com/js2005happy/nyra/releases/latest/download/nyra-macos-x64 && chmod +x nyra
  2. 2

    运行首次启动向导Run the setup wizard

    三步配好模型 Key，然后就能交第一件任务。Three steps to add a model key, then you can hand it the first task.

    $./nyra setup
  3. 3

    自检Check everything

    检查 Key、网络、目录权限和磁盘。Checks your key, network, folder permissions and disk.

    $./nyra doctor
  4. 4

    可选：装进 PATHOptional: put it on your PATH

    用仓库里的安装脚本装到 ~/.local/bin，以后直接输入 nyra。The install script in the repo puts it in ~/.local/bin, so you can just type nyra.

    $git clone https://github.com/js2005happy/nyra.git && bash nyra/scripts/install-node-macos.sh

    二进制目前未签名、未公证。如果是从浏览器下载的，第一次运行时在访达里右键 → 打开，放行一次。The binary isn’t signed or notarized yet. If you downloaded it in a browser, right-click it in Finder and choose Open the first time.

  1. 1

    在 PowerShell 里一键安装Install from PowerShell

    装到 ~\nyra，加进 PATH，并建好桌面快捷方式。Installs to ~\nyra, adds it to PATH and creates desktop shortcuts.

    PS>irm https://raw.githubusercontent.com/js2005happy/nyra/main/scripts/install-node.ps1 | iex
  2. 2

    运行首次启动向导Run the setup wizard

    打开一个新的 PowerShell 窗口再运行。Open a new PowerShell window first.

    PS>nyra setup
  3. 3

    自检Check everything

    检查 Key、网络、目录权限和磁盘。Checks your key, network, folder permissions and disk.

    PS>nyra doctor
  4. 4

    想要窗口界面？Prefer a window?

    桌面 App（预览）的安装包在 Release 里：The desktop app (preview) installer is in the release:

    Nyra_0.5.1_x64-setup.exeNyra_0.5.1_x64_en-US.msi

    安装包和 exe 目前未签名，SmartScreen 会提示：点“更多信息 → 仍要运行”。The installers and the exe aren’t signed yet, so SmartScreen will warn you: choose More info → Run anyway.

    $git clone https://github.com/js2005happy/nyra.git && bash nyra/scripts/install-node.sh
  1. 1

    在电脑上开启配对Start pairing on your computer

    先在电脑上装好 Nyra，然后运行：Install Nyra on your computer first, then run:

    $nyra ui --pair
  2. 2

    用手机扫码Scan the code with your phone

    手机和电脑连同一个 Wi‑Fi，用相机扫终端里的二维码。配对码 5 分钟内有效，只能用一次。Put your phone on the same Wi‑Fi and scan the QR code in the terminal with the camera. The pairing code lasts 5 minutes and works once.

  3. 3

    添加到主屏幕Add it to your home screen

    iPhone：Safari 里点分享 → 添加到主屏幕。Android：Chrome 右上角 ⋮ → 添加到主屏幕。iPhone: in Safari tap Share → Add to Home Screen. Android: in Chrome tap ⋮ → Add to Home screen.

    不经应用商店，没有账号。手机直接连你电脑上的 Nyra，工具仍在电脑上执行。No app store and no account. Your phone talks to the Nyra on your computer, and tools still run there.
