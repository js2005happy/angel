入门Getting started

Nyra 是什么？What is Nyra?

Nyra 是一个在你自己电脑上运行的开源 AI agent。它能读代码、改文件、运行命令、联网查资料，并在每次写入和执行之前先征求你的同意。Nyra is an open-source AI agent that runs on your own computer. It reads code, edits files, runs commands and researches online, and it asks for your permission before every write and every command.

运行它需要什么？What do I need to run it?

Python 3.10 或更高版本、git，以及一个模型 API Key（例如 DEEPSEEK_API_KEY）。使用本地 Ollama，或本机已登录的 Codex CLI 时不需要 Key。macOS、Linux、Windows 都可以运行。Python 3.10 or later, git, and a model API key (for example DEEPSEEK_API_KEY). No key is needed with a local Ollama model or a Codex CLI already signed in on your machine. It runs on macOS, Linux and Windows.

命令行和网页界面有什么区别？How do the command line and the web UI differ?

两者背后是同一个 agent。命令行适合直接在终端里工作；python3 -m nyra ui --open 会打开本地网页界面，在浏览器里会话、审批和看 diff。网页界面只监听 127.0.0.1，每次启动都生成新的随机 token。Both use the same agent. The command line suits working directly in your terminal; python3 -m nyra ui --open opens the local web UI, where you chat, approve and read diffs in the browser. The web UI listens on 127.0.0.1 only and creates a new random token on every launch.

模型与费用Models and cost

支持哪些模型？Which models are supported?

共 14 个预设：DeepSeek（默认）、xAI Grok、OpenAI、通义千问、Kimi、智谱 GLM、Gemini、OpenRouter、Mistral、Groq、Together、本地 Ollama、本机 Codex，以及可自定义的 OpenAI 兼容接口（custom）。运行 python3 -m nyra --list-providers 查看全部。14 presets in total: DeepSeek (default), xAI Grok, OpenAI, Qwen, Kimi, Zhipu GLM, Gemini, OpenRouter, Mistral, Groq, Together, local Ollama, local Codex, and a custom OpenAI-compatible endpoint. Run python3 -m nyra --list-providers to see them all.

Nyra 收费吗？Does Nyra cost anything?

Nyra 本身免费，以 MIT 许可开源。你使用的模型服务按各自的价格收费，费用在你和模型服务商之间结算。/status 能看到当前会话的 Token 用量。Nyra itself is free and open source under the MIT License. The model service you use charges its own prices, billed between you and that provider. /status shows the token usage of the current session.

主模型出错时会自动换模型吗？Will it switch models if the main one fails?

默认不会。模型兜底默认关闭，只有你自己开启后才会生效，而且只会切换到你列出的备用模型。开启后，网页界面会明确显示发生了切换。Not by default. Model fallback is off until you turn it on yourself, and even then it only switches to the backup models you list. When it happens, the web UI shows the switch.

安全与隐私Safety and privacy

它会不经同意就改我的文件吗？Will it change my files without asking?

默认的 auto 模式下不会：每次写文件和执行命令都会先问你。readonly 模式完全不写、不执行；只有当你主动选择 full 模式，它才不再确认。Not in the default auto mode: it asks before every file write and every command. readonly mode never writes or runs anything; only when you choose full mode yourself does it stop asking.

改错了怎么办？What if it gets something wrong?

每次写入前都会自动存检查点。/undo 撤销上一步，/rewind 回到更早的检查点，且不会覆盖别人在中途做的改动。检查点只覆盖本地文件，撤销不了已执行命令或网络请求的外部影响。A checkpoint is saved before every write. /undo reverts the last step and /rewind returns to an earlier checkpoint, without overwriting changes someone else made in between. Checkpoints cover local files only; they cannot undo the external effects of commands or network requests that already ran.

Nyra 是沙箱吗？Is Nyra a sandbox?

不是操作系统级沙箱。文件工具不能写到工作目录之外，但 shell 命令以你的用户权限运行。处理不可信的代码时，请使用 --sandbox e2b（需要 E2B 账号和 Key），或虚拟机、容器等隔离环境。It is not an OS-level sandbox. File tools can’t write outside the working directory, but shell commands run with your user permissions. For untrusted code, use --sandbox e2b (requires an E2B account and key) or an isolated environment such as a virtual machine or container.

数据Data

我的数据存在哪里？Where is my data stored?

会话、记忆、证据、检查点、定时任务和配置都保存在你电脑上的 ~/.nyra 目录里。Nyra 本身不收集遥测，也不会把这些文件上传给项目维护者——维护者没有任何服务器在接收它们。Sessions, memory, evidence, checkpoints, scheduled tasks and configuration are stored in ~/.nyra on your computer. Nyra collects no telemetry and never uploads these files to the maintainers, who run no server that receives them.

哪些内容会发给模型服务商？What gets sent to the model provider?

你的指令，以及完成任务时放进上下文的文件内容和工具结果，会发送给你配置的模型服务商，适用该服务商的隐私政策。web_search 和 web_fetch 会访问你查询的网站。API Key 只从环境变量读取，不写入文件或日志。Your instructions, plus the file contents and tool results placed in context to do the task, go to the model provider you configure, under that provider’s privacy policy. web_search and web_fetch contact the sites being queried. API keys are read from environment variables and never written to files or logs.

怎么反馈问题，或者参与贡献？How do I report a problem or contribute?

在 GitHub Issues 提交问题或建议，欢迎提 Pull Request。提交前请运行 python3 -m unittest discover tests（目前 540 项单元测试，全部 mock，不需要 Key）。Open an issue or suggestion on GitHub Issues; pull requests are welcome. Before submitting, run python3 -m unittest discover tests (currently 540 unit tests, all mocked, no key needed).

它和 Codex、OpenCode 这类工具是什么关系？How does it relate to tools like Codex or OpenCode?

Nyra 的代码是原创的。它借鉴了 Codex、OpenCode、Goose、OpenHands 等开源 agent 的设计思想，来源写在 DESIGN.md 里，没有复制它们的源码。Nyra’s code is original. It borrows design ideas from open-source agents such as Codex, OpenCode, Goose and OpenHands, credited in DESIGN.md, without copying their source code.

路线图Roadmap

有桌面和手机 App 吗？Are there desktop and mobile apps?

macOS、Windows、iOS、Android 客户端正在开发，网站上的截图是设计预览。目前可用的是命令行和本地网页界面。macOS, Windows, iOS and Android apps are in development; the screenshots on this site are design previews. Today you can use the command line and the local web UI.

接下来会做什么？What’s coming next?

规划中的方向包括：让 agent 跑在你自己云服务器上的「云电脑」，以及手机与电脑配对审批。可靠性方面，长任务断点续跑、费用上限和多 agent 状态板排在前面。具体以 ROADMAP.md 为准。Planned directions include a “cloud computer” that runs the agent on your own cloud server, and phone–desktop pairing for approvals. On reliability, resumable long tasks, spending limits and a multi-agent status board come first. ROADMAP.md is the source of truth.
