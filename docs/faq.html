入门Getting started

Nyra 是什么？What is Nyra?

Nyra 是一个跑在你自己电脑上的开源 AI agent。它能读懂项目、改代码、跑命令、联网查资料并附上出处；写文件和执行命令之前，默认都会先问你。Nyra is an open-source AI agent that runs on your own computer. It reads your project, edits code, runs commands and researches the web with sources, and by default it asks you before it writes a file or runs a command.

运行它需要什么？What do I need to run it?

一台 macOS（Apple 芯片或 Intel）、Windows（x64）或 Linux（x64 / arm64，需要 glibc）电脑，再加一个模型服务商的 Key。Nyra 是单文件二进制，不用装 Python、Node 或 Bun。A Mac (Apple silicon or Intel), a Windows PC (x64) or a Linux machine (x64 / arm64 with glibc), plus a key from a model provider. Nyra is one self-contained binary; you don’t need Python, Node or Bun.

怎么安装？How do I install it?

最快的方式是从 GitHub Releases 下载对应平台的二进制，运行 setup 向导；Windows 也可以在 PowerShell 里一键安装。点页面顶部的“安装”按钮可以看到每个平台的步骤。The quickest way is to download the binary for your platform from GitHub Releases and run the setup wizard; on Windows you can also install with one line in PowerShell. The Install button at the top of the page shows the steps for each platform.

Nyra 收费吗？Does Nyra cost anything?

Nyra 本身免费、开源，以 MIT 许可发布。调用模型产生的费用在你和模型服务商之间结算；也可以用本机的 Ollama 模型，或复用本机的 Codex 登录。Nyra itself is free and open source under the MIT License. Model usage is billed between you and your model provider; you can also use a local Ollama model or reuse the Codex sign-in on your machine.

支持哪些模型？Which models does it support?

DeepSeek（默认）、xAI Grok、OpenAI、通义千问、Kimi、智谱、Gemini、OpenRouter、Mistral、Groq、Together、本机 Ollama、本机 Codex 登录，以及任何兼容 OpenAI 接口的自定义服务。运行 nyra --list-providers 查看全部。DeepSeek (the default), xAI Grok, OpenAI, Qwen, Kimi, Zhipu GLM, Gemini, OpenRouter, Mistral, Groq, Together, a local Ollama, the Codex sign-in on your machine, and any custom OpenAI-compatible endpoint. Run nyra --list-providers to see them all.

还没有 Key，能先试试吗？Can I try it without a key?

可以先运行 nyra --help、--version 和 --list-providers，它们不联网、不花钱。没设 Key 就跑模型任务时，Nyra 会打印设置说明后退出，不会发出任何请求。也可以直接用本机的 Ollama。You can run nyra --help, --version and --list-providers; they don’t touch the network or cost anything. If you start a model task without a key, Nyra prints setup instructions and exits without sending a request. You can also use a local Ollama model.

安全与控制Safety and control

我的 Key 存在哪里？Where are my keys stored?

环境变量里的 Key 永远优先。在 Nyra 界面里填的 Key，密码箱已解锁时存进本机加密密码箱，否则写进 ~/.nyra/keys.json（macOS 和 Linux 上文件权限 0600）。页面和接口只显示掩码，比如 sk-…abcd，明文不会回传。A key in an environment variable always wins. A key you enter in the Nyra app goes into the encrypted local vault when it’s unlocked, otherwise into ~/.nyra/keys.json (mode 0600 on macOS and Linux). The app and its API only show a mask like sk-…abcd; the plain key is never sent back.

它会不会乱改我的文件？Will it mess with my files?

默认的 auto 模式下，写文件和跑命令前都会先问你。文件工具写不出当前工作目录，.git、.nyra 和 AGENTS.md 这类路径默认拒写。每次写入前都会存检查点，改错了可以 /undo。In the default auto mode it asks before writing a file or running a command. File tools can’t write outside your working folder, and paths like .git, .nyra and AGENTS.md are off limits by default. A checkpoint is saved before every write, so /undo can take it back.

有哪几种审批模式？What approval modes are there?

readonly 只读文件、联网查资料，不写也不执行；auto（默认）写文件或执行命令前逐项问你；full 不再确认，适合你明确信任的任务。随时可以用 --mode 或会话里的 /mode 切换。readonly only reads files and searches the web, never writes or runs anything; auto (the default) asks before each write or command; full stops asking, for tasks you explicitly trust. Switch with --mode, or /mode inside a session.

“始终允许”会不会放得太宽？Is “Always” too broad?

不会。在 v0.5.1 里，“始终允许”只对同一个文件或同一条命令（同一目录）生效，而且只管本次会话。想长期放行，可以在 config.json 的 permissions 里写规则，比如 Bash(npm run build)。按命令前缀记规则、可选本会话或本项目、在 设置 → 权限与审批 里撤销，这些在下个版本上线。No. In v0.5.1, “Always” covers only the same file or the exact same command in the same folder, and only for this session. For standing permissions, write rules under permissions in config.json, such as Bash(npm run build). Prefix rules for this session or project that you can revoke under Settings → Permissions & approvals are coming in the next release.

改错了怎么办？What if it gets something wrong?

/undo 撤销上一步，/rewind 3 回到三步之前。检查点只管本地文件，撤销不了 shell 命令、网络请求这类外部副作用。/undo reverts the last step and /rewind 3 goes back three. Checkpoints cover your local files; they can’t undo side effects such as shell commands or network requests.

能先看计划再执行吗？Can I review a plan before it runs?

可以。nyra --plan 会只读地写出 plan.md，你审过之后用它的 SHA-256 批准执行；计划改动一个字节，旧的批准就失效。Yes. nyra --plan writes plan.md in read-only mode; once you’ve reviewed it, approve that exact version by its SHA-256. Change a single byte and the old approval no longer counts.

手机、自动化与其他Phone, automation and more

手机端要装 App 吗？Do I need an app on my phone?

不用。在电脑上运行 nyra ui --pair，用手机浏览器打开终端给出的地址、输入配对码，再添加到主屏幕就行（扫码配对在下个版本上线）。手机和电脑需要在同一个 Wi‑Fi 下，工具始终在电脑上执行。手机端目前只在模拟器里验证过，真机反馈很欢迎。No. Run nyra ui --pair on your computer, open the address it prints in your phone’s browser, enter the code, and add it to your home screen (pairing by QR code is coming in the next release). Your phone and computer need to be on the same Wi‑Fi, and tools always run on the computer. The phone app has only been tested in emulation so far; reports from real devices are welcome.

能让它定时干活吗？Can it run tasks on a schedule?

可以。nyra schedule add 按间隔或每天定时跑任务，到点后进入任务队列。遇到需要审批的操作会停下来等你，定时任务也不能用 full 模式。Yes. nyra schedule add runs a task on an interval or daily, and each run joins the task queue. Anything that needs approval stops and waits for you, and scheduled tasks can’t use full mode.

为什么系统提示安装包不安全？Why does my system warn me about the installer?

Windows 和 macOS 的安装包目前还没有签名和公证。Windows 上点“更多信息 → 仍要运行”；macOS 上在访达里右键 → 打开，放行一次即可。各平台的安装文档里有详细步骤。The Windows and macOS packages aren’t signed or notarized yet. On Windows choose More info → Run anyway; on macOS right-click the file in Finder and choose Open, once. The install guides for each platform have the details.

怎么卸载？How do I uninstall it?

用安装脚本装的，加 --uninstall 再跑一次（Windows 是 -Uninstall）；手动下载的二进制，直接删掉文件即可。你的数据目录 ~/.nyra 会保留，需要的话自己删除。If you used an install script, run it again with --uninstall (-Uninstall on Windows); if you downloaded the binary yourself, just delete it. Your data folder ~/.nyra is kept; delete it yourself if you want.

遇到问题去哪里反馈？Where do I report a problem?

到 GitHub Issues 提问题，最好附上报错原文和 nyra doctor 的输出。Open an issue on GitHub Issues, ideally with the exact error and the output of nyra doctor.
