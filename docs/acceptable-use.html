Nyra 能替你读写文件、执行命令、访问网络。能力越实际，越需要清楚的边界。这份政策列出不允许的用途，以及使用 agent 时应有的基本做法。Nyra can read and write files, run commands and use the network on your behalf. The more real the capability, the clearer the limits need to be. This policy lists what is not allowed, and the basic practices expected when you run an agent.

1. 适用范围Scope

本政策适用于 Nyra 软件、本网站，以及项目的 GitHub 仓库（包括 Issues 与 Pull Request）。它是服务条款的一部分。MIT 许可证授予你的代码权利不受影响；本政策描述的是项目维护者对使用方式的期望与社区规则。

This policy applies to the Nyra software, this website and the project’s GitHub repository (including issues and pull requests). It forms part of the Terms of Use. It does not reduce the rights the MIT License grants you over the code; it sets out the maintainers’ expectations for use and the rules of the community.

2. 不允许的用途What is not allowed

不得使用 Nyra 从事或协助以下行为：

  • 违反适用法律法规的活动；
  • 未经授权访问、扫描、攻击或干扰你无权操作的系统、网络或账户；
  • 编写、传播或部署恶意软件、勒索软件或用于破坏的代码；
  • 欺诈、钓鱼、垃圾信息，或冒充他人与机构；
  • 骚扰、威胁、跟踪他人，或未经同意收集、公开他人的个人信息；
  • 生成或传播涉及未成年人的性内容，或其他宣扬暴力、仇恨的违法内容；
  • 获取用于制造大规模杀伤性武器的具体帮助；
  • 以违反网站条款或给对方造成过重负担的方式批量抓取网站；
  • 规避你所用模型服务商的安全措施或使用政策。

Do not use Nyra to do, or help do, any of the following:

  • Anything that breaks applicable law;
  • Accessing, scanning, attacking or disrupting systems, networks or accounts you are not authorized to use;
  • Writing, spreading or deploying malware, ransomware or destructive code;
  • Fraud, phishing, spam, or impersonating people or organizations;
  • Harassing, threatening or stalking people, or collecting or exposing their personal information without consent;
  • Creating or distributing sexual content involving minors, or other unlawful violent or hateful content;
  • Getting specific help to build weapons capable of mass casualties;
  • Scraping websites in bulk in ways that breach their terms or overload them;
  • Circumventing the safety measures or usage policies of the model providers you use.

3. 使用 agent 的基本做法Responsible agent practices

  • 保持人在回路中：默认的 auto 模式会逐项询问，请认真看过再批准。只对你完全信任的任务使用 full 模式；
  • 先计划，再执行：较大的改动先用 --plan 审查计划；
  • 隔离不可信代码：Nyra 不是操作系统级沙箱，请使用 --sandbox e2b、虚拟机或容器；
  • 谨慎对待无人值守任务：定时任务和多 bot 群聊同样以你的身份行事，你仍对结果负责；
  • 尊重他人：只在你有权操作的代码库、账户和数据上运行 Nyra；
  • 核实输出：模型可能出错，重要结论请查看来源或自行验证。
  • Keep a human in the loop: the default auto mode asks before each action, so read before you approve. Use full mode only for tasks you fully trust;
  • Plan before acting: review larger changes with --plan first;
  • Isolate untrusted code: Nyra is not an OS-level sandbox, so use --sandbox e2b, a virtual machine or a container;
  • Take care with unattended work: scheduled tasks and multi-bot rooms also act as you, and you remain responsible for the results;
  • Respect others: run Nyra only on code, accounts and data you are entitled to use;
  • Check the output: models make mistakes, so check sources or verify important conclusions yourself.

4. 第三方政策Third-party policies

你使用的模型服务商（如 DeepSeek、xAI、OpenAI 等）、E2B、MCP 服务器和你访问的网站都有自己的使用政策。你需要同时遵守这些政策；如果它们比本政策更严格，以更严格的为准。

The model providers you use (such as DeepSeek, xAI and OpenAI), E2B, MCP servers and the websites you visit have their own usage policies. You must follow them as well; where they are stricter than this policy, the stricter rule applies.

5. 社区规则Community conduct

在仓库的 Issues、讨论和 Pull Request 中，请保持尊重、就事论事。不要发布他人的个人信息、API Key 或任何违法内容。

In the repository’s issues, discussions and pull requests, be respectful and stay on topic. Do not post other people’s personal information, API keys or any unlawful content.

6. 报告问题Reporting

发现滥用、违反本政策的行为或安全漏洞，请在 GitHub Issues 告诉我们。涉及可被利用的安全细节时，请先开一个不含细节的 Issue，说明需要私下沟通。

Report abuse, breaches of this policy or security vulnerabilities on GitHub Issues. For security details that could be exploited, first open an issue without the details and say you need to talk privately.

7. 违反的后果Enforcement

Nyra 运行在你自己的设备上，我们无法、也不会远程监控或停用它。对于违反本政策的行为，维护者可以拒绝相关贡献、删除内容，或限制相关账户参与项目仓库。

Nyra runs on your own devices; we cannot and do not monitor or disable it remotely. For breaches of this policy, the maintainers may decline contributions, remove content, or restrict the accounts involved from taking part in the project repository.

8. 政策变更与语言Changes and language

我们可能更新本政策，更新会发布在本页面并修改生效日期。本政策提供简体中文和英文版本；如两者不一致，以简体中文版本为准。

We may update this policy; updates are posted on this page with a new effective date. This policy is available in Simplified Chinese and English; if the two differ, the Simplified Chinese version governs.

安装 NyraInstall Nyra

五步，几分钟。只需要 Python 和 git。Five steps, a few minutes. All you need is Python and git.

0 / 5 步已完成steps done

macOS

  1. 1✓

    前置要求Prerequisites

    需要 Python 3.10 或更高版本，以及 git。先确认一下版本：You need Python 3.10 or later, and git. Check your versions first:

    python3 --version
    git --version
  2. 2✓

    克隆仓库Clone the repository

    把代码下载到本地的 nyra 文件夹，然后进入它。Download the code into a local nyra folder, then step into it.

    git clone https://github.com/js2005happy/nyra.git nyra && cd nyra
  3. 3✓

    设置一个模型 KeySet a model key

    14 个模型预设任选其一，这里以 DeepSeek 为例。Key 只从环境变量读取，不会写进文件。Pick any of the 14 model presets; DeepSeek is shown here. Keys are read from environment variables and never written to files.

    export DEEPSEEK_API_KEY=sk-...
  4. 4✓

    运行Run it

    在终端里开始交互会话，或者打开本地网页界面。Start an interactive session in the terminal, or open the local web UI.

    终端交互Terminal
    python3 -m nyra
    本地网页界面Local web UI
    python3 -m nyra ui
  5. 5✓

    验证Verify

    能打印出版本号，就说明装好了。If it prints a version number, you’re all set.

    python3 -m nyra --version
