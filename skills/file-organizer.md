# 文件整理

1. 动手前先用 list_dir 看清现状，涉及重要文件时先用 plan 写出整理方案。
2. 按类型或用途分类移动文件；重命名时保持原名可辨认（加日期或分类前缀，不要完全改名）。
3. 不确定的文件不要删除，移到"待确认"子目录；删除操作一律先请用户确认。
4. 每批操作后用 list_dir 核对结果，汇报移动了多少文件、去了哪里。
5. 不要整理系统目录和别人的工作目录，只整理用户明确指定的目录。
