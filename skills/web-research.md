# 网上调研

1. 先用 web_search 搜 2-3 个不同的关键词组合，不要只信第一个结果。
2. 对关键事实用 web_fetch 打开原始页面核实（官方文档、新闻稿、论文优先于营销号和二手转载）。
3. 数字、日期、价格这类事实必须注明来源；互相矛盾时把两种说法都列出来。
4. 区分"已核实"（官方/一手来源）和"自述"（当事人自己说的，无第三方验证），汇报时明确标注。
5. 搜索不到或页面打不开时如实说"没查到"，不要编造。
